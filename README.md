# Business Analysis of a Scientific Paper Review and Approval Process

## Project Overview

An academic Business Analyst project focused on analyzing the scientific paper review and approval process. The project examined process inefficiencies and applied business analysis techniques to identify root causes, define system functional requirements, and design a data model to support paper and review management.

## Project Objectives

- Identify root causes of prolonged review time, delayed reviewer feedback, and manual activities.
- Define system functional requirements and interactions to improve review, feedback, and paper management activities.
- Structure data and relationships for managing scientific papers, reviews, users, and review records.

## My Contributions

- **Root Cause Analysis:** Applied a Fishbone Diagram to identify root causes of process issues, including prolonged review time, delayed reviewer feedback, and manual activities.
- **Functional Requirements Analysis:** Designed Use Case Diagrams to define system functional requirements and interactions for review, feedback, and paper management.
- **Data Modeling:** Designed an Entity-Relationship Diagram (ERD) to structure data entities and relationships involving papers, reviews, users, and review records.
- **Team Collaboration:** Collaborated with four team members to coordinate analysis tasks, integrate project deliverables, and maintain consistency across the final report and presentation materials.
